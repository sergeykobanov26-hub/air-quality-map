# Аналитическая платформа России: качество воздуха и речной сток

Интерактивное веб-приложение для анализа экологических данных России.
Два независимых модуля: **качество воздуха** и **паводки/наводнения**.

## О проекте

Платформа собирает данные из открытых источников и представляет их в виде
интерактивных карт, графиков и выводов. Пользователь может выбирать города,
реки, периоды и загрязнители — и сразу видеть результат.

## Что внутри

### Модуль 1. Качество воздуха

- **65 городов России** (население > 50 000).
- **6 загрязнителей:** PM2.5, PM10, NO₂, O₃, SO₂, CO.
- **Карта** с цветными точками по уровню загрязнения (шкала AQI).
- **Графики:** динамика во времени, средние по городам, распределение.
- **Нормативы:** рекомендации ВОЗ (2021) и ПДК России (СанПиН 1.2.3685-21).
- **Автоматические выводы:** превышения норм, лидеры по чистоте и загрязнению.

### Модуль 2. Паводки и наводнения

- **20 крупнейших рек России.**
- **История 30 дней** + **прогноз 14 дней** речного стока.
- **Карта** с речной сетью (Natural Earth) и точками расчёта стока.
- **Графики:** динамика стока, средние значения по рекам.
- **Прогноз роста стока:** регионы и города с риском подтопления.

## Стек

- **Python 3.11**
- **Streamlit** — веб-приложение
- **Folium** — интерактивные карты
- **Plotly** — интерактивные графики
- **Pandas** — обработка данных
- **Requests** — работа с API

## Источники данных

- **Качество воздуха:** [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api)
- **Речной сток:** [Open-Meteo Flood API](https://open-meteo.com/en/docs/flood-api) (модель GloFAS, Copernicus)
- **Справочник городов:** компиляция открытых данных (Росстат + OpenStreetMap)
- **Справочник рек:** координаты ключевых точек на реках России
- **Речная сеть (линии):** [Natural Earth](https://www.naturalearthdata.com/) (public domain)
- **Нормативы воздуха:** [ВОЗ (2021)](https://www.who.int/publications/i/item/9789240034228), [СанПиН 1.2.3685-21](https://docs.cntd.ru/document/573500115)
