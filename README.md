# Аналитическая платформа России: качество воздуха и речной сток

Интерактивное веб-приложение для анализа экологических данных России.
Два независимых модуля: **качество воздуха** и **паводки/наводнения**.

## О проекте

Платформа собирает данные из открытых источников и представляет их в виде
интерактивных карт, графиков и выводов. Пользователь может выбирать города,
реки, периоды и загрязнители — и сразу видеть результат.

## Что внутри

### Модуль 1. Качество воздуха

- **65 городов России** (население > 50 000).
- **6 загрязнителей:** PM2.5, PM10, NO₂, O₃, SO₂, CO.
- **Карта** с цветными точками по уровню загрязнения (шкала AQI).
- **Графики:** динамика во времени, средние по городам, распределение.
- **Нормативы:** рекомендации ВОЗ (2021) и ПДК России (СанПиН 1.2.3685-21).
- **Автоматические выводы:** превышения норм, лидеры по чистоте и загрязнению.

### Модуль 2. Паводки и наводнения

- **20 крупнейших рек России.**
- **История 30 дней** + **прогноз 14 дней** речного стока.
- **Карта** с речной сетью (Natural Earth) и точками расчёта стока.
- **Графики:** динамика стока, средние значения по рекам.
- **Прогноз роста стока:** регионы и города с риском подтопления.

## Стек

- **Python 3.11**
- **Streamlit** — веб-приложение
- **Folium** — интерактивные карты
- **Plotly** — интерактивные графики
- **Pandas** — обработка данных
- **Requests** — работа с API

## Источники данных

- **Качество воздуха:** [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api)
- **Речной сток:** [Open-Meteo Flood API](https://open-meteo.com/en/docs/flood-api) (модель GloFAS, Copernicus)
- **Справочник городов:** компиляция открытых данных (Росстат + OpenStreetMap)
- **Справочник рек:** координаты ключевых точек на реках России
- **Речная сеть (линии):** [Natural Earth](https://www.naturalearthdata.com/) (public domain)
- **Нормативы воздуха:** [ВОЗ (2021)](https://www.who.int/publications/i/item/9789240034228), [СанПиН 1.2.3685-21](https://docs.cntd.ru/document/573500115)

## Как запустить

### Для пользователя — открыть готовое приложение

Приложение **уже развёрнуто** и работает в облаке. Ничего устанавливать не нужно.

**Открыть: [russia-air.streamlit.app](https://russia-air.streamlit.app)**

Приложение доступно с любого устройства:
- **С компьютера** — работает в любом современном браузере (Chrome, Firefox, Edge, Safari).
- **С телефона** — открывается, но возможны ограничения бесплатного хостинга Streamlit Cloud
  (медленная загрузка, ограниченная мобильная вёрстка).

**Что можно сделать в приложении:**

- Переключаться между разделами **«Качество воздуха»** и **«Паводки и наводнения»**.
- Выбирать города, реки, периоды и загрязнители через фильтры в боковой панели.
- Смотреть интерактивные карты, графики и таблицы.
- Читать автоматически сформированные выводы по данным.

### Для разработчика — запустить локально

Если вы хотите развернуть проект у себя (для доработки или изучения кода):

**Требования:**
- Python **3.11**
- Git (опционально)

**Шаги:**

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/sergeykobanov26-hub/air-quality-map.git
   cd air-quality-map
   ```

   Или скачайте ZIP через кнопку **Code → Download ZIP** на GitHub и распакуйте.

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv .venv
   ```

   Активируйте:
   - **Windows (PowerShell):**
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   - **macOS / Linux:**
     ```bash
     source .venv/bin/activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   streamlit run app.py
   ```

5. **Откройте в браузере:** `http://localhost:8501`

### Развёртывание на Streamlit Cloud (для справки)

Проект развёрнут на **Streamlit Community Cloud** — бесплатном хостинге для Streamlit-приложений.

**Ключевые моменты деплоя:**
- Python фиксируется через **Advanced settings** при создании приложения (`Python 3.11`).
- Зависимости устанавливаются из `requirements.txt`.
- При пуше в `main` приложение **автоматически пересобирается**.

**Важно:** Streamlit Cloud по умолчанию использует **последнюю версию Python** — для этого проекта она не подходит из-за отсутствия готовых wheel-пакетов для `pillow` и других библиотек. Поэтому **обязательно** выберите `3.11` в настройках при создании.
